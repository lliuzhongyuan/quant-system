# V2300-V3100 production architecture

## Non-negotiable data contract
1. No synthetic quotes, K-lines, ROE, news, backtest metrics, or latency values.
2. Primary universe/realtime list: Sina Finance A-share list.
3. Secondary realtime verification: Tencent Finance.
4. Daily K-line: Tencent QFQ first; Sina Finance fallback. If both fail or fewer than 80 bars are returned, the stock is not promoted.
5. Production scan is blocked when universe < 3500, scan coverage < 90%, data is stale, or secondary quote checks materially diverge.
6. Every production dataset carries source/time/data-quality metadata.

## V2300-V3100 modules
- V2300: unified multi-factor A-H signal engine.
- V2400: verified industry/sector board ranking from Sina sector nodes.
- V2500: signal/strategy board and confidence layers.
- V2600: daily compact full-universe archive, enabling future no-survivorship research.
- V2700: risk-budget portfolio research plan; broker execution remains disabled.
- V2800: walk-forward research gate; no historical performance claim until enough snapshots exist.
- V2900: production data-quality gate and secondary-source cross-check.
- V3000: Apple-inspired responsive research terminal with light/dark mode and mobile navigation.
- V3100: source-adapter architecture prepared for persistent realtime backend/WebSocket without weakening the data contract.

## What is deliberately not claimed yet
- No exchange-direct licensed feed is claimed.
- No second-by-second realtime SLA is claimed on GitHub Pages.
- No full-history, survivorship-bias-free backtest is claimed until the archive has enough history.
- D is a price/volume cost proxy, not true Level-2 chip distribution.
- Portfolio output is research-only and does not place orders.

## Sources
The current public adapters use documented/observed public Sina and Tencent finance endpoints. Endpoint behavior is tested in CI; failure causes a visible block rather than fallback to fake values.
