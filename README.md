# 智选量化终端 V2300

个人 A 股研究/选股终端，核心原则：**真实数据、全市场扫描、多策略共振、风险优先、失败不伪造**。

## V2300 本轮升级
- 全市场：新浪财经公开 A 股列表，实际扫描约 4400+ 股票；688 / 北交所 / ST / 退市等过滤。
- 技术引擎：MA5/10/20/60、RSI14、MACD、KDJ、ATR14、60日位置、量比、换手、5/20日收益、回撤。
- A~H：低位启动、主升突破、回踩二波、筹码结构穿透代理、龙头强度、超跌反转、量价异动、风险拦截。
- 评分：趋势、位置、动量、量能/资金代理、基本面快照、风险扣分 → 质量分 / 机会分 / 共振 / 信号置信度。
- 风控：ATR 止损、ATR 目标、风险收益比、账户风险预算与仓位计划。
- 数据质量：不再依赖容易失败的东方财富实时 push2；PE/PB/市值直接使用新浪行情快照，失败不伪造。
- 回测：滚动历史样本、固定双边成本代理、止损/目标/时间退出，并明确幸存者偏差限制。
- 新闻：新浪财经 7×24 真实抓取；抓取失败保持空状态。
- 扫描状态：实时写入 `data/scan_status.json`，记录 universe / scanned / failed / progress。

## 全新 UI
V2300 使用 Apple HIG 思路重新设计：清晰的信息层级、简洁导航、系统化字体与间距、浅色/深色适配、谨慎使用半透明材质；同时保留交易终端需要的数据密度、表格、评分标签和快速搜索。详细说明见 `index.html`、`app.js`、`style.css`。

## 数据链路
- 股票池 / 日K：新浪财经公开接口。
- 指数：上证、深证、创业板、沪深300。
- PE / PB / 市值 / 换手：股票行情快照。
- 新闻：新浪财经 7×24。
- 所有失败接口都采用“空数据/最近成功快照”策略，不用模拟数据补齐。

## 回测边界
`backtest.py` 只使用当前保存的高质量候选历史文件进行滚动研究，因此**不是无幸存者偏差的全市场历史回测**。当前加入固定双边成本代理，但尚未模拟真实涨跌停成交队列、盘口冲击和完整滑点。严肃策略上线前必须继续做全市场历史数据库与样本外验证。

## 自动化
- `market-snapshot.yml`：交易时段约每 5 分钟更新市场快照。
- `daily-scan.yml`：交易日前后执行全市场扫描、新闻和研究回测；支持手动触发。
- `backtest.yml`：保留周末研究任务。
- `v2100-validate.yml`：Python、JavaScript、JSON、文件和 UI 基础验证。

GitHub Pages 适合静态研究终端，不适合作为持久化实时后端。若未来要求 30 秒级全市场 4400+ 股票持续重算，应迁移计算层到 Cloud Run / VPS / Worker，并让 Pages 只负责展示。

## 安全边界
本项目是研究和选股系统，不连接券商、不自动下单。策略信号不构成投资建议；“主力动能”和“筹码结构穿透”均为公开行情数据上的代理指标，不代表真实资金账户或交易所筹码分布。
