# 智选量化终端 V3100

个人 A 股研究/选股终端，核心原则：**真实数据、全市场扫描、多源交叉验证、多策略共振、风险优先、失败不伪造**。

## 数据源优先级（生产）
- A 股股票宇宙：Sina Finance 公开行情列表。
- 日 K：Tencent Finance QFQ → Eastmoney QFQ → Sina Finance；至少 80 根有效 K 线才允许进入技术计算。
- 实时交叉验证：Sina 主行情 + Tencent 二次校验；样本偏差超过 1% 时数据质量闸门失败。
- 指数：上证、深证、创业板、沪深300真实行情。
- 行业：Sina 行业节点与真实成分行情；接口不可用时显示 UNAVAILABLE。
- 新闻：Sina 7×24、Eastmoney 7×24、Eastmoney 财经/个股新闻、CLS 财联社；源级状态独立记录，失败源不会用假新闻替代。

## V2300~V3100
- 技术引擎：MA5/10/20/60、RSI14、MACD、KDJ、ATR14、60日位置、量比、换手、5/20日收益、回撤。
- A~H：低位启动、主升突破、回踩二波、筹码结构穿透代理、龙头强度、超跌反转、量价异动、风险拦截。
- 评分：趋势、位置、动量、量能/资金代理、基本面快照、风险扣分 → 质量分 / 机会分 / 共振 / 信号置信度。
- 风控：ATR 止损、ATR 目标、风险收益比、账户风险预算与仓位计划。
- 数据质量：覆盖率不足、过期、接口失败、交叉验证异常时直接 BLOCKED，不把旧数据、随机值或模拟数据冒充真实行情。
- 回测：滚动历史样本、成本代理、止损/目标/时间退出；明确幸存者偏差与成交约束边界。
- 历史：持续归档每日真实股票宇宙，为无幸存者偏差回测和 Walk-forward 积累样本。

## UI
Apple HIG 风格的信息层级 + 专业交易终端信息密度：浅/深色模式、响应式导航、快速搜索、信号表格、市场驾驶舱、风险与研究页面。GitHub Pages 使用显式部署工作流，前端 CDN 失败时显示明确错误，不显示空白页面或伪数据。

## 自动化
- `market-snapshot.yml`：交易时段约每 5 分钟更新真实市场快照。
- `daily-scan.yml`：交易日前后执行全市场扫描、新闻、研究与数据质量校验；只允许通过闸门的数据提交到生产。
- `backtest.yml`：周末研究任务。
- `pages.yml`：main 分支变更后显式部署 GitHub Pages。
- `v2100-validate.yml`：Python、JavaScript、JSON、文件与 UI 基础验证。

## 边界
GitHub Pages 是静态展示层，不是持久化实时行情服务器。若未来要求秒级/30秒级 4400+ 全市场持续重算，需要将计算和实时数据缓存迁移到 Cloud Run/VPS/Worker，并由 Pages 展示。当前系统不连接券商、不自动下单；“主力动能”和“筹码结构穿透”是公开行情数据上的代理指标，不代表真实资金账户或交易所筹码分布。

> 生产验收：每次代码升级后先验证前端、再验证真实数据覆盖率，未通过数据闸门时禁止发布生产行情。
